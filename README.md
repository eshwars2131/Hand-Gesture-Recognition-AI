✋ Hand Gesture Recognition AI

A real-time hand tracking application built using Python, OpenCV, and MediaPipe. The project uses a webcam to detect hand landmarks and visualize hand movements.

🚀 Features

- Real-time webcam input
- Hand landmark detection
- Visual hand skeleton and connections
- Live video display
- Press "Q" to quit the application

🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe

📦 Installation

1. Clone the repository

git clone https://github.com/eshwars2131/Hand-Gesture-Recognition-AI.git
cd Hand-Gesture-Recognition-AI

2. Install dependencies

pip install -r requirements.txt

▶️ Run the Project

python app.py

Allow webcam access if prompted. Press Q to close the application.
